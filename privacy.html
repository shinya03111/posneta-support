ポスネタ プライバシーポリシー

制定日: 2026年8月7日

「ポスネタ」(以下「本アプリ」)の開発者(以下「開発者」)は、本アプリにおける利用者情報の取り扱いについて、以下のとおり定めます。

1. 収集する情報

本アプリは、利用者の個人情報・利用データを一切収集しません。

  • アカウント登録・ログインは不要で、その仕組み自体がありません
  • アクセス解析・トラッキング(計測SDK等)は行いません
  • 広告は表示しません(広告SDKも組み込んでいません)

2. データの保存場所

本アプリで作成した下書き・ネタ・タグ・定型文などのデータは、すべて利用者の端末内のデータベース(SQLite)にのみ保存されます。開発者を含む外部のサーバーへ送信されることはなく、開発者がこれらのデータにアクセスすることもできません。

なお、OS(iOS / Android)の端末バックアップ機能により、端末内のアプリデータがバックアップの対象になる場合があります。これは OS の機能であり、開発者がそのデータにアクセスすることはありません。

3. 通知について

本アプリの通知は、利用者が下書きごとに設定するリマインド用のローカル通知のみです。通知は端末内で完結し、プッシュ通知サーバー等の外部サービスは使用しません。通知の利用には OS の許可ダイアログによる利用者の許可が必要で、OS の設定からいつでも無効にできます。

4. X(旧Twitter)への投稿について

本アプリは X の API を使用していません。「Xへ投稿」機能は、X アプリまたはブラウザの投稿画面を開くだけのものです。

  • このとき、下書きの本文テキストは OS の共有機構(URLスキーム / ブラウザ起動)を経由して X に渡ります
  • 投稿を実行するかどうかは、X の画面上で利用者自身が決定します
  • X に渡った後のテキストの取り扱いには、X社の利用規約およびプライバシーポリシーが適用されます
  • 開発者が、投稿内容や投稿の有無を取得することはありません

5. クリップボード

[コピー]操作を行った場合、本文テキストは端末のクリップボードに書き込まれます。本アプリがクリップボードの内容を読み取ることはありません。

6. データの削除

  • 下書きの削除はごみ箱経由で行われ、30日経過後に自動的に完全削除されます(ごみ箱から即時の完全削除も可能です)
  • 本アプリをアンインストールすると、端末内のすべてのデータが削除されます
  • 開発者は利用者のデータを保持していないため、開発者側での削除手続きは存在しません(削除は利用者の端末操作で完結します)

7. ポリシーの変更

本ポリシーの内容を変更する場合は、本ページで告知します。重要な変更がある場合は、アプリのアップデート情報等でもお知らせします。
